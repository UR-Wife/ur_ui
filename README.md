# ur_ui

Phoenix function components for the UR black/red/white design system.
See [USAGE.md](USAGE.md) for installation, component APIs, and examples.

## Credits

The component structure and behaviour are ported from
[shadcn/ui](https://github.com/shadcn-ui/ui), which is distributed under the
MIT license. ur_ui reimplements that structure with Phoenix function
components and its own UR design tokens; it does not copy shadcn's styling.
